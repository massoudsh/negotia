# ADR 0002 — انتخاب اولین کانال ورودی MVP

- وضعیت: پذیرفته‌شده
- مرتبط با: GitHub issue #4

## زمینه
باید بین ایمیل (IMAP/Gmail API) و WhatsApp Business API برای اولین کانال ورودی مکالمه در MVP یکی انتخاب شود.

## گزینه‌ها
- **WhatsApp Business API:** نیاز به تأیید Meta Business، شریک BSP، هزینه per-conversation و زمان راه‌اندازی چند هفته‌ای دارد. برای pilot سریع مناسب نیست.
- **ایمیل (IMAP):** پروتکل باز و پایدار، بدون تأیید شخص ثالث، قابل تست فوری با هر صندوق ایمیل، و همچنان کانال غالب مکاتبات B2B صادرات/واردات (پیش‌فاکتور، مذاکره رسمی) است.

## تصمیم
کانال اول MVP **ایمیل** است. ingest از طریق پارس کردن پیام‌های ایمیل (فرستنده، گیرنده، موضوع، متن، زمان دریافت) به مدل `Conversation`/`Message` انجام می‌شود (`src/ingest/emailIngest.js`، issue #5). واتساپ به Phase 3 (یکپارچه‌سازی بومی) موکول می‌شود.

## دلایل
- سریع‌ترین مسیر برای اولین pilot با مشتری واقعی، بدون وابستگی به تأیید یا هزینه شخص ثالث.
- ایمیل همچنان کانال رسمی غالب برای پیش‌فاکتور و مذاکره ثبت‌شده در تجارت خارجی است.

## پیامدها
- ورودی ایمیل نیازمند پارس متن آزاد است (کمتر ساخت‌یافته از webhook واتساپ)؛ منطق `ingestEmail` باید نویز/امضا/quote-reply را در نظر بگیرد (نسخه فعلی ساده است و در فاز بعد بهبود می‌یابد).
